TokenDesk macOS v1.8.0 / Windows v1.2.0 · 使用统计与模型显示版

新增：
1. 每日 ChatGPT 主动使用时间统计。
   - 仅当 ChatGPT 标签页处于前台且最近 5 分钟内有键盘、鼠标、滚动或触控交互时累计。
   - 多个标签页不会重复累计。
   - Chrome 本地保存最近 7 天统计。

2. 最近 7 天柱状统计。
   - “每日使用时间”：显示每天主动使用 ChatGPT 的时间。
   - “每日用量”：显示每周剩余额度当日下降的百分点。
   - “每日用量”不是 Token 数，不代表 API Token 消耗。

3. 运行任务显示模型。
   - 当 ChatGPT 页面能够暴露当前模型选择时，在“思考 / 工作”任务旁显示模型名称。
   - 例如 GPT-5.6、GPT-5.6 Thinking 等。
   - 如果 ChatGPT 使用 Auto / 自动路由，TokenDesk 只能显示页面可见的选择状态，不能保证获得后端实际路由模型。
   - 页面无法识别模型时显示“未识别”，不会猜测。

保留：
- 5 小时额度剩余 20% 或以下提醒；
- 每周额度剩余 20% 或以下提醒；
- 5 小时额度刷新提醒；
- 每周额度刷新提醒；
- 空闲 Work 模式误判修复；
- 额度历史曲线；
- 思考 / 工作任务区分；
- 本机 127.0.0.1 安全桥接。

版本：
- macOS：v1.8.0，Intel x86_64 / Apple Silicon arm64，最低 macOS 12。
- Windows：v1.2.0，win-x64 / win-arm64。
- Chrome 扩展：v1.8.0。
