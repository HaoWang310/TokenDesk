# TokenDesk for Windows v1.2.6

Windows 10 / 11 原生桌面版本，复用 TokenDesk 的 Chrome 扩展与本机桥接协议。

## 功能

- Windows 系统托盘常驻；
- ChatGPT 5 小时 / 每周剩余额度；
- 5 小时剩余 20% 或以下提醒；
- 每周剩余 20% 或以下提醒；
- 5 小时额度刷新提醒；
- 每周额度刷新提醒；
- 额度重置时间与 7 天本机历史；
- 运行任务统计，并区分「思考 / 工作」；
- 运行任务显示 ChatGPT 页面当前所选模型（页面能够识别时）；
- 统计每天 ChatGPT 主动使用时间；
- 本周（周一至周日）每日使用时间柱状图，每周一 00:00 自动清零；
- 本周（周一至周日）每天的每周额度下降百分点柱状图，每周一清零本地周统计；
- 最多统计 20 个活动任务，面板展开前 8 个；
- 任务完成、停止或失联后自动移除；
- Chrome / Edge 可加载同一份 Chromium 扩展；
- 配对码与历史只保存在本机；
- 本机桥接只监听 `127.0.0.1:18743`；
- 可选择登录 Windows 后自动启动到系统托盘。

## 系统要求

- Windows 10 2004（19041）或更高版本；
- 推荐 Windows 11；
- 发布包提供 `win-x64` 与 `win-arm64` 两个自包含版本，无需单独安装 .NET。

## 安装

1. 从 GitHub Actions 下载与你电脑匹配的发布包：
   - 常见 Intel / AMD Windows 电脑：`TokenDesk-Windows-win-x64`
   - Windows on ARM：`TokenDesk-Windows-win-arm64`
2. 解压后运行 `TokenDesk.exe`。
3. 点击「打开扩展文件夹」。
4. Chrome / Edge 扩展管理页打开开发者模式，选择「加载已解压的扩展程序」并选择 `Chrome_Extension` 文件夹。
5. 将 TokenDesk 面板中的 64 位配对码复制到浏览器扩展并保存。
6. Chrome 保持登录 ChatGPT，即可同步额度。

额度监控无需保持 ChatGPT 页面打开；运行任务监控、模型识别和主动使用时间统计需要对应 ChatGPT 网页标签页保持打开。主动使用时间只在 ChatGPT 标签页处于前台且最近 5 分钟内有交互时累计。

## 隐私

Windows 端只接收净化后的额度字段与任务元数据（标题、URL、运行阶段、时间）。不会从 Chrome 扩展传输 ChatGPT 对话正文、密码、Cookie 或 bearer token 到 TokenDesk 桌面端。

- v1.2.6 修复 Chrome/Edge 扩展重载后，旧 ChatGPT 标签页向无效扩展上下文发送消息导致的 extract.js:38 错误；消费 runtime.lastError 并终止失效脚本的重复发送。更新扩展至 v1.8.5 后需刷新所有 ChatGPT 标签页。
- v1.2.5 增加 Chrome/Edge 扩展“检查模型识别”诊断按钮，明确定位网页监听脚本是否加载、选择器是否存在及是否暴露名称；加强新版输入框模型控件识别，适用于 Windows / Mac 的同一扩展 v1.8.4。Work 页面可能不提供模型标签，此时不会猜测底层模型。请同时更新桌面端和扩展并刷新 ChatGPT 网页。
- v1.2.4 修复新版 ChatGPT 模型识别：支持无 data-testid 的输入框模型/模式按钮（__composer-pill）及 GPT-6 系列名称。仅能读取 Instant、Thinking、Pro 或推理档位时显示“模式”，不推测实际底层模型；关闭选择器时不会因临时重绘将已有识别结果抹掉。需要同时更新 Chrome / Edge 扩展至 v1.8.3，并刷新 ChatGPT 页面。
- v1.2.3 将“近 7 天”滚动图表改成自然周（周一至周日）：每周一 00:00 按设备本地时间自动清零本周使用时间和本地每日额度下降统计，同时保留已记录的本周数据；不影响 ChatGPT 官方 5 小时 / 每周额度重置。安装前的网页活动历史无法补录。
- v1.2.2 优化近 7 天使用统计：浏览器扩展每 10 秒单独上报活跃网页使用时间，不再依赖 Thinking/Working 任务识别；不足 1 分钟的用时会如实显示。该统计从安装新版扩展并使用后开始积累，不能回填安装前的历史。
- v1.2.1 修复额度提醒重复弹出：5 小时 / 每周的“额度已刷新”和“剩余 20% 或以下”提醒，在每个真实额度周期内都最多显示一次；关闭后本周期不再重复，下一次真实刷新后重新解锁。
- v1.2.0 在保留误判修复和额度提醒的基础上，新增 7 天使用统计与模型显示。
