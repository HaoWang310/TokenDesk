TokenDesk v1.8.0 installation

Recommended Terminal install:

  bash "/full/path/to/TokenDesk_v1.8.0/install.command"

Then open Chrome:
  chrome://extensions

Reload / load the TokenDesk extension from:
  ~/Library/Application Support/TokenDesk/Chrome_Extension

v1.8.0 adds seven-day active-time statistics, quota-use bar charts, and active-task model labels.
